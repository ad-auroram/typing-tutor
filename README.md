# Adaptive Typing Tutor

A web-based adaptive typing tutor built with Next.js.

The app tracks typing performance by round, identifies weak letters and bigrams (like `th` or `er`), and adapts future prompts to target those patterns. It includes:

- Practice mode for timed typing rounds
- Profile view with progress metrics (accuracy and WPM)
- Pattern-level error tracking to support personalized practice

Live demo: https://typing-tutor-lyart.vercel.app/

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open http://localhost:3000 in your browser.
